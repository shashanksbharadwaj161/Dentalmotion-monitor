# DentalMotion Monitor — セットアップ・使用ガイド

**歯科研究用・手の動きリアルタイム計測システム**
歯磨きやフロスなど口腔ケア動作中の手首・手の動きを無線で記録します。
3Dモデルのリアルタイム表示、加速度グラフ、衝撃検出に対応。
すべてのセッションをCSVファイルとして自動保存し、Excelで開けます。

> **このガイドは技術的な知識がない方でも読めるように書かれています。**
> WiFiに接続してアプリをインストールできれば、このシステムを使えます。

---

## このシステムとは？

患者や研究者がセンサーグローブを手に装着します。歯磨き（または口腔ケア動作）中に、グローブがリアルタイムでノートPCに動作データを無線送信します。ダッシュボードで動きをリアルタイム表示し、後で分析するために記録します。

```
[センサーグローブ]  ──WiFi──►  [このPC]  ──►  [ブラウザ画面]
  患者の手に装着        バックグラウンドで      3D動作・グラフ・
                         自動起動              録画を表示
```

---

## 必要なもの

| アイテム | 詳細 |
|---------|------|
| **センサーグローブ** | New Horizons OS ボード（すでに組み立て済み） |
| **Windows PC / ノートPC** | Windows 10 または Windows 11 |
| **WiFiネットワーク** | PCとグローブが**同じWiFiに接続**している必要があります |
| **ブラウザ** | Chrome・Edge・Firefox など何でも可 |

> グローブは電源を入れると自動的にWiFiに接続します。
> 出荷時にクリニック・研究室のネットワーク情報が設定されています。
> WiFiが変わった場合は **第6節「WiFiを変更する」** をご覧ください。

## 初回セットアップ（最初の1回だけ）

### 手順1 — Python をインストールする

Pythonは計測ソフトウェアを動かすための無料プログラムです。

1. ブラウザで **https://www.python.org/downloads/** を開く
2. 大きな黄色い **「Download Python」** ボタンをクリック
3. ダウンロードされたファイルをダブルクリックして実行
4. **⚠️ 重要：** インストール画面の最初に **「Add Python to PATH」** というチェックボックスが表示されます。必ずチェックを入れてから次へ進んでください

5. **「Install Now」** をクリック（約2分かかります）
6. 完了したら **「Close」** をクリック

**確認方法：**
- キーボードの `Windowsキー` + `R` を押す
- `cmd` と入力してEnterキーを押す
- 黒い画面が開いたら `python --version` と入力してEnterキーを押す
- `Python 3.13.2` のように表示されれば成功です

---

### 手順2 — 必要なコンポーネントをインストールする

1. `dentalmotion-monitor` フォルダを開く（このREADMEが入っているフォルダ）
2. フォルダ上部の**アドレスバー**（フォルダのパスが表示されている場所）をクリックする
3. `cmd` と入力してEnterキーを押す（黒いウィンドウが開きます）
4. 以下の1行をコピーして黒いウィンドウに貼り付け、Enterキーを押す：

```
pip install -r gateway\requirements.txt -r imu_viewer\requirements.txt
```

5. 文字がたくさん流れますが正常です。1〜3分待ちます。
6. `Successfully installed ...` と表示されたら完了です。

> ✅ 手順1・2は最初の1回だけです。
> 次回からは `START.bat` をダブルクリックするだけで使えます。

## 毎回の使い方 — セッションの記録

### 手順3 — グローブを装着して電源を入れる

1. 患者または研究者がセンサーグローブを手に装着する
2. グローブ本体のスイッチで電源を入れる
3. LEDが点滅している間はWiFiに接続中です。LEDが点灯（点滅しない状態）になるまで待ちます（約10〜15秒）

---

### 手順4 — ダッシュボードを起動する

1. `dentalmotion-monitor` フォルダを開く
2. **`START.bat` をダブルクリック**する
3. 黒いウィンドウが2つ開きます。**閉じないでください**（バックグラウンドで動作します）
4. ブラウザが自動的に開いてダッシュボードが表示されます

ブラウザが自動で開かない場合は、手動で **http://127.0.0.1:8765** を開いてください。

---

### 手順5 — グローブを接続する

ダッシュボードが開いたとき、最初はデータが表示されていない場合があります。

1. 上部の **「Network」タブ**（4番目のタブ）をクリック
2. **「Rediscover Board」**（ボードを再検索）ボタンをクリック
3. 5〜10秒待つ
4. ステータスが **「Stream: live」** に変わり、グラフが動き始めます

---

### 手順6 — セッションを録画する

1. **「Recordings」タブ**（3番目のタブ）をクリック
2. **「▶ Start Recording」** をクリック
3. 患者に歯磨き・口腔ケア動作を行ってもらう
4. 終了したら **「■ Stop Recording」** をクリック

ファイルはデスクトップの **「DentalMotion\_Recordings」** フォルダに自動保存されます。

**ファイル名の例：** `imu_3CDC75413DC8_20260703_142500.csv`（デバイスID\_年月日\_時分秒）

**Excelで開く方法：** ファイルをダブルクリックするだけで自動的にExcelが開きます。
各行が1回のセンサー計測データです（1秒間に約100行）。
列：`timestamp`（時刻）、`seq`（連番）、`ax ay az`（加速度X/Y/Z）、`gx gy gz`（角速度X/Y/Z）

---

### 手順7 — システムを終了する

1. 録画中の場合は **「■ Stop Recording」** をクリックして停止する
2. `dentalmotion-monitor` フォルダにある **`STOP.bat` をダブルクリック**する
3. 黒いウィンドウが2つ閉じます
4. グローブの電源を切る

---

## ダッシュボードの見方

### タブ1 — 3D View（3D表示）

グローブの向きをリアルタイムで3Dモデルとして表示します。

| 表示 | 意味 |
|------|------|
| **Packets/s** | データ送信レート。使用中は56〜100が正常 |
| **Seq Drops** | 欠落パケット数。少数は正常。多い場合はWiFi干渉の可能性あり |
| **Pitch / Roll / Yaw** | 手の3方向の回転角度（度） |
| **Peak \|g\| / Shocks** | 最大加速度と急激な動作（2.5g超）の回数。「Reset」で初期化 |
| **金色の矢印** | 重力方向。手首の傾きを確認するのに便利 |
| **Pause ボタン** | 3D表示を一時停止（録画は継続） |
| **⛶ ボタン** | 全画面表示 |

---

### タブ2 — Charts（グラフ）

過去15秒間の動作データをスクロールグラフで表示：

- **Acceleration（加速度 g）** — X・Y・Z軸の力（±8g）。歯磨きストロークが確認できます
- **Gyroscope（角速度 °/s）** — 回転速度。手首の回転・ひねり動作が確認できます
- **Magnitude \|g\|（合成加速度）** — 動作の総合的な強さ。点線（1g）が安静時の基準線

---

### タブ3 — Recordings（録画）

録画の開始・停止と過去の録画ファイル一覧を表示します。

---

### タブ4 — Network（ネットワーク）

グローブのWiFi接続を管理します。
- データが表示されない → **「Rediscover Board」** をクリック
- WiFiが変わった → **「Change WiFi Credentials」** を使用

## 第6節 — WiFiを変更する

クリニック・病院のWiFiが変わった場合に使用してください。

### 方法A — ダッシュボードから変更（まずこちらを試してください）

*グローブが現在接続されていてデータが表示されているときに使用できます。*

1. **「Network」タブ**を開く
2. **「Network Name (SSID)」** 欄に新しいWiFi名を入力
3. **「Password」** 欄にパスワードを入力（👁 で確認できます）
4. **「Apply & Reboot Board」** をクリック
5. カウントダウンが表示されます（グローブが設定を保存して再起動しています）
6. カウントダウン後、このPCを新しいWiFiに接続する
7. **「Rediscover Board」** をクリック → 10秒以内に再接続されます

---

### 方法B — ハードウェア復旧

*グローブがどのネットワークにも接続できない場合に使用します。*

準備：**WiFi機能付きのスマートフォン・タブレット・別のPCのいずれか1台**

1. グローブの**電源を完全に切る**
2. **BOOTボタン**（基板上の小さなボタン）を**押したまま**にする
3. BOOTボタンを押しながら**電源を入れる**
4. 電源が入ってから**3秒間押し続け**て、その後離す
5. グローブが一時的なWiFi **`NHOS-Setup-3CDC75`**（パスワードなし）を作成します
6. スマートフォンで **`NHOS-Setup-3CDC75`** に接続する
7. ブラウザで **http://192.168.4.1** を開く
8. 新しいWiFi名とパスワードを入力して保存する
9. グローブが再起動し新しいネットワークに接続します
10. スマートフォンを通常のWiFiに戻す
11. このPCで **「Network」タブ** → **「Rediscover Board」** をクリック

## トラブルシューティング

| 症状 | 対処方法 |
|------|---------|
| データが表示されない・グラフが動かない | グローブのLEDが点灯しているか確認 → **Network**タブ → **Rediscover Board** |
| 「Board not visible」と表示される | 10秒待ってから **Rediscover** をもう一度クリック |
| 「gateway offline」と表示される | 黒いウィンドウを両方閉じて `START.bat` を再度ダブルクリック |
| ページが白いまたはエラーが出る | 10秒待ってブラウザを更新する |
| `python` が認識されない | 「Add Python to PATH」にチェックを入れずにインストールしています。手順1からやり直してください |
| Packets/s が 0 のまま | **Network**タブ → **Rediscover Board** をクリック |
| 信号強度（RSSI）が −75 dBm 以下 | グローブをWiFiルーターに近づけてください |
| 録画ファイルが見つからない | デスクトップの `DentalMotion_Recordings` フォルダを確認してください |
