Connect a New Board

For a board that has never been on WiFi before (or was moved to a new location). Power the board on so it's broadcasting its own setup hotspot — the status LED blinks blue while it's in this mode — then enter your WiFi network's name and password below and click Connect. This computer will briefly switch its own WiFi to the board's hotspot, hand it the credentials, and switch back automatically — no need to do anything on a phone or visit any setup page yourself.

Board not broadcasting a setup hotspot? Power it fully off, then on, five times in a row (each within a few seconds) — this forces it back into setup mode (blue blink), even if it already has WiFi saved. No buttons to hold.

Change WiFi Credentials

Enter the new network name and password, then click Apply. The board will save the credentials and reboot. After it reboots, connect this computer to the new network and click Rediscover below.

Reconnect Board

After the board reconnects to the new network, trigger rediscovery so this gateway can find it again. Sends a FindMe probe, waits 5 seconds, then re-establishes the data stream.

Board Unreachable? Use AP Setup Mode

If the board cannot connect to WiFi at all (wrong password, network unavailable), or if "Connect a New Board" above can't find it, use manual AP setup mode.

  1. Power the board fully off, then on, five times in a row (each within a few seconds of the last) — no buttons to hold. The status LED starts blinking blue once it's in setup mode. (Freshly unboxed boards start in this mode automatically on first power-on.)
  2. The board creates a WiFi access point named DentalMotion-Setup-3CDC75 (no password).
  3. Connect this computer or a phone to that access point.
  4. Open a browser and go to http://192.168.4.1
  5. Enter the new WiFi SSID and password and save.
  6. Board reboots, connects to the new network, and the LED turns solid green once it's streaming. Return here and click Rediscover.

The setup page is served by the board firmware — not by this viewer.
